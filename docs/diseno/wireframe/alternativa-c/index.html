Alternativa C · Privilegia tasa de errores

El mismo recorrido que la Alternativa A con una pantalla más: antes de cobrar se interpone una confirmación del pago. Siete pantallas y doble validación.

Flujo

01 Menú y precios → 02 Detalle del plato → 03 Revisar el pedido → 04 Pago → 05 Confirmar el pago → 06 En preparación → 07 Listo para retirar

Las dos validaciones son 03 · Revisar el pedido y 05 · Confirmar el pago. Desde la confirmación se puede volver a cualquiera de las dos sin perder el pedido.

Pantallas

01 Menú y precios Lista completa con precios y filtros alimenticios opcionales. 02 Detalle del plato Cantidad, descripción y precio antes de agregar al pedido. 03 Revisar el pedido Primera validación: se corrigen cantidades y se quitan productos. 04 Pago Identificación y medio de pago. Todavía no se cobra. 05 Confirmar el pago Segunda validación: el monto exacto antes de que se mueva el dinero. 06 En preparación Código de retiro y permiso explícito para irse. 07 Listo para retirar La notificación y la pantalla que la acompaña.
