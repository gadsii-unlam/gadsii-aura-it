Qué se construye y qué se simula acá

El checkout de Mercado Pago es una integración externa, y la consigna permite simularla en el MVP. Se puede probar el flujo completo con un pago simulado y aprender igual si el usuario encuentra valor. Lo que sí tiene que estar construido de verdad es el componente propio: el pedido, su estado y el aviso de listo.
